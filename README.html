喜悦能力库 · 规范与样例

能力库保存可共享的功能定义与规范，不保存账号、运行状态或真实服务配置。首版支持声明式流程，不支持任意代码执行。

能力包

manifest.schema.json 描述基本结构；Agent 还会检查字段唯一性、模板引用和凭证隔离。包包含 id、version、name、description、fields、steps。

字段类型用途
text / number控制台表单与调用参数，支持默认值
credential_refBitwarden 条目引用，不是密钥；不可作为语音模板变量
步骤行为
say生成提示事件，然后继续；目前只有文字预览
confirm提示并等待用户确认
timer提示并开始计时，到期进入下一步

提供的例子

  • capabilities/tea-guide.json：用户确认开始浸泡后，计时三分钟，之后等待出汤确认。
  • capabilities/stretch-guide.json：确认准备后，启动一分钟活动计时。

安装

Agent 默认扫描相邻目录 capabilities/*.json，只安装尚不存在的能力且默认停用；也可以在控制台导入 JSON。运行中的任务保留创建时的步骤快照。

编写与验证

python3 check.py

自检检查规范和包的基础结构。实际运行语义以 Agent 的校验为准。未来的网络工具、代码插件与外部 Agent 扩展另行版本化，不要在当前包里塞入脚本命令。
