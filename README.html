喜悦 Voice · 能力库

可独立交付：五个 JSON 样例、能力包结构规范、离线校验器与文字预览。只需要 Python 3.9+ 标准库。预览不运行 Agent、不联网、不产生声音、不写任务状态。提示音和语音确认需要使用支持 tone 和 ask 的 Agent，已通过软件模拟验证。

先在本地验证

在本仓库目录执行。所有等待与确认都会明确标记为模拟，无需等待实际计时：

python3 check.py
python3 -m unittest -v
python3 check.py capabilities/short-timer.json --preview
python3 check.py capabilities/check-reminder.json --preview --value content=查看清单
python3 check.py capabilities/tea-guide.json --preview --value tea=示例茶
python3 check.py capabilities/stretch-guide.json --preview

校验成功退出码为 0；格式、重复 ID、无效模板或输入失败为 1，命令参数错误为 2。可传多个 JSON 文件校验；不传路径时检查本仓库全部样例。--value 只接受普通文字或数字，勿传入凭证或个人数据。

结构与运行边界

manifest.schema.json 定义顶层 id、version、name、description、fields、steps。未知属性、未知字段或步骤类型均被拒绝。

类型实际含义
text / number普通表单值；默认值和调用输入都是字符串。仅这些字段可以用于 {{key}} 文字替换。number 在执行时须为合法数字。
secretAgent 管理的密钥表单字段，配置写入后独立加密保存，读取仅显示配置状态。包内不能给出非空默认值，也不能用于步骤模板。
credential_refAgent 可保存的 bitwarden:item:条目UUID 引用；不是密钥，也不表示执行器会自动取用 Bitwarden。禁止非空默认值和文字模板引用。
say生成 speech 提示事件并继续；事件存在不等于已播放或送达。
confirm生成提示并停在 waiting，须由 Agent 接收确认后继续；离线预览自动模拟确认。
tone请求播放内置提示音。text 取 cue 或 alarm，单次播放。设备需要本地 PCM 播放。
ask播报确认问题并等待。对话中的下一次收听继续现有会话，后台启动的流程等待用户唤醒后确认。需要本机模型处理确认意图，也可在控制台手动确认。
timer生成提示并进入 timer，到期继续。seconds 必须为 1–604800 的整数；其他步骤可省略 seconds 或设为 0。

校验器覆盖当前结构中的类型、长度、计时条件、额外属性以及字段唯一性、模板引用和凭证隔离。为兼容 Go Agent，字符串上限还按 UTF-8 字节检查（JSON Schema 本身以字符计数）。它只实现本仓库规范使用的关键字，不是通用 JSON Schema 引擎。Agent 的导入与运行校验仍是最终边界，离线通过不证明设备、管理权限或服务配置可用。

能力清单可选 "menu": true。启用后控制台会在侧栏创建入口，用于运行已有步骤、配置和查看该能力的运行记录。

版本、启用和权限分开管理

  • 能力版本：version 是作者声明的内容版本，建议使用语义化版本；当前 Agent 只校验非空且不超过 32 字节，不比较版本、不自动更新。同 ID 重复导入会失败；启动扫描只安装尚不存在的 ID，不覆盖用户配置。不能靠改版本号替换旧包。当前没有覆盖升级/降级接口；可用新 ID 并行试用，计划仍需显式选择对应能力。
  • 启用状态：外部样例导入后默认停用；在控制台「自动化 → 导入流程」可把样例转换成普通流程，检查后保存。需要按能力清单原样安装时，目录安装使用 Agent 的 -abilities /path/to/capabilities 参数，不必保留相邻仓库布局。内建能力的启用策略另由 Agent 管理。
  • 停用边界：停用会阻止新任务启动；运行中的任务已保存步骤快照，不随包变化，停用不等于取消。已有任务请单独取消，计划请单独停用。停用期间的到期失败与重试以 Agent 的当前实现为准。
  • 权限边界：包内没有 permissions、网络授权或代码执行字段。启用仅允许执行已支持的声明式步骤，不授予 shell、文件、联网或设备控制权限。管理接口访问权限由 Agent 负责；凭证字段不等于工具执行授权。
  • 运行状态：任务、确认、计时、计划、事件和配置保存在 Agent，不回写共享能力包。包的 version、Agent 的状态文件版本与未来协议版本互不等同。离线预览不实现持久化、重启恢复、计划重试、取消或语音送达。

交付与贡献

发布时固定本仓库提交与 Agent、控制台版本。用户可以单独导入所需样例。新增或改动样例需运行上述离线检查和预览，并在兼容 Agent 中进行导入/任务验证。不要提交真实凭证、个人输入、运行状态或媒体。网络工具、任意代码、动态计时表达式、外部 Agent 适配和自动升级均尚未由本仓库实现，须有独立协议与运行权限设计后另行交付。

软件离线验证范围；未进行真实服务调用、录音、播放、刷机或物理设备测试。
